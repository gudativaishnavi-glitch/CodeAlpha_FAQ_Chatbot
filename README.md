# AI FAQ Chatbot

## About the Project
An AI-powered FAQ chatbot developed using Python,
Natural Language Processing and Streamlit.

## Features
- Interactive chatbot interface
- Automatic FAQ answering
- Text similarity matching
- TF-IDF vectorization
- Cosine similarity

## Technologies Used
- Python
- Streamlit
- Scikit-learn
- NLP

## How to Run

Install dependencies:

pip install -r requirements.txt

Run the application:

streamlit run app.py
